## Implementation notes

* Engine layer: `src/physics/world/softBuild.ts`, `softAttach.ts`, `softCut.ts`, `soft.ts` (`softPrestep`, skin readback), `energy.ts` (edge-spring elastic energy), `snapshot.ts` (soft runtime state in `WorldSnapshot.softs`, which is how soft bodies work with time travel). Model: `softMesh.ts`, `core/hull.ts`, `softMaterial.ts`, `softBudget.ts`, `ropeGen.ts`; document fields `SoftEntity.attachments` etc. (sanitised in `serialize.ts`).
* UI: tools and commands in `src/ui/extensions/soft-*.ts`, inspector in `src/ui/inspector/softSf.ts`, example scenes in `src/model/content/soft-*.ts`.
* Known limits (docs/LIMITATIONS.md): soft scenes rewind approximately (engine caches), 400 Hz tyres unstable while rolling (defaults 150 Hz), volumetric meshes use convex hulls, no per-body update rate (economy mode instead). New dependency: none.
* Still to do by others: connect package SH's imported meshes in `softSurface` (adapter point: `src/model/softMesh.ts`).
