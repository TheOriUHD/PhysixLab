# 18 · UI polish, layout, outliner, inspector, telemetry, onboarding (package UI)

Depends on: foundation (panel/command registries). Everything must work at 1280×720 up to 4k, mouse + keyboard (+ touch from CM-12), with all themes (VZ-50).

## Layout
- [ ] UI-1 — Dockable, resizable panels: panels (Scenes, Prefabs, Maps, Outliner, Inspector, World, Telemetry, Timeline, Logic, Help…) can be dragged between dock regions (left, right, bottom), tabbed, split, collapsed, popped out as floating windows (draggable/resizable, z-order), and maximised; layout persisted per user; named layout presets (Build, Simulate, Analyse, Present) + reset
- [ ] UI-2 — Floating inspector that follows selection (pinnable near the object or fixed), compact "quick properties" bar in the viewport for the selected body (mass, material, lock, key actions)
- [ ] UI-3 — Simple vs Advanced mode: Simple hides advanced sections (components, logic, solver, collision layers, analysis) and shows friendly labels; per-user toggle; persists; first-run suggests Simple

## Inspector
- [ ] UI-10 — Inspector upgrades: unit toggles per field (SI/imperial), scrub-drag on labels, math expressions in numeric fields (`2*9.81`, `5 ft`), reset-to-default per field, multi-selection editing with "mixed" display, search/filter fields, collapsible sections remembered, copy/paste properties between objects (all or selected sections), property presets
- [ ] UI-11 — Calculators in the inspector: mass from density×volume, density from mass, spring constant from period/frequency, damping ratio, moment of inertia readout, terminal velocity, projectile range, pendulum period — shown contextually, with a "set" button writing values into the selected object
- [ ] UI-12 — Live readout panel for the selected body while simulating (position, velocity, speed, acceleration, forces, contacts, energy) with units, copy, pin

## Outliner
- [x] UI-20 — Outliner: tree with groups/folders (from ED-20), drag to reorder/reparent with drop indicators, multi-select ranges (Shift/Ctrl), inline rename, eye/lock/solo toggles, colour tags and tag chips, per-row thumbnails (offscreen renders cached), search with filters (type, material, tag, locked/hidden, has-component), sort modes, context menu, virtualised for thousands of rows (evidence: tests/outlinerTree.test.ts [rows, filters, ranges, drop plans, solo, tags, virtual window, document fields]; e2e/tests/outlinerA.mjs [shift/ctrl ranges, ArrowDown, F2/double-click rename, drop-before / drop-inside indicators + reorder/reparent with undo, eye/lock/solo, rendered thumbnails, colour tags + chips, tag:/type:/is: filters + dropdown, sort, 4000-row virtualisation]; src/ui/outliner/*). Notes: thumbnails are real cached off-screen renders for bodies (compound bodies draw all parts); groups, lights, paths, joints and soft bodies show their type icon (no renderable shape in the outliner) — see LIMITATIONS. Solo isolates by hiding unrelated entities and marking them `soloHid` so clearing the solo restores exactly them; the outliner is virtualised with a fixed 28 px row.
- [x] UI-21 — Selection sets: named selection groups (save/recall), quick-select by tag from the outliner (evidence: e2e/tests/outlinerA.mjs [save a set from the selection, recall it, survives serialize/parse, saving is undoable, tag-bar and row-chip quick-select]; tests/outlinerTree.test.ts [selectionSets sanitising + undo, idsWithTag]; sets live in `settings.selectionSets`, entity `colorTag` / `tags` / `solo` / `soloHid` are sanitised in src/model/sanitize/outlinerMeta.ts)
