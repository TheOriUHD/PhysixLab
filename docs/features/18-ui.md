# 18 · UI polish, layout, outliner, inspector, telemetry, onboarding (package UI)

Depends on: foundation (panel/command registries). Everything must work at 1280×720 up to 4k, mouse + keyboard (+ touch from CM-12), with all themes (VZ-50).

## Layout
- [ ] UI-1 — Dockable, resizable panels: panels (Scenes, Prefabs, Maps, Outliner, Inspector, World, Telemetry, Timeline, Logic, Help…) can be dragged between dock regions (left, right, bottom), tabbed, split, collapsed, popped out as floating windows (draggable/resizable, z-order), and maximised; layout persisted per user; named layout presets (Build, Simulate, Analyse, Present) + reset
- [ ] UI-2 — Floating inspector that follows selection (pinnable near the object or fixed), compact "quick properties" bar in the viewport for the selected body (mass, material, lock, key actions)
- [ ] UI-3 — Simple vs Advanced mode: Simple hides advanced sections (components, logic, solver, collision layers, analysis) and shows friendly labels; per-user toggle; persists; first-run suggests Simple

## Inspector
- [ ] UI-10 — Inspector upgrades: unit toggles per field (SI/imperial), scrub-drag on labels, math expressions in numeric fields (`2*9.81`, `5 ft`), reset-to-default per field, multi-selection editing with "mixed" display, search/filter fields, collapsible sections remembered, copy/paste properties between objects (all or selected sections), property presets
- [ ] UI-11 — Calculators in the inspector: mass from density×volume, density from mass, spring constant from period/frequency, damping ratio, moment of inertia readout, terminal velocity, projectile range, pendulum period — shown contextually, with a "set" button writing values into the selected object
- [ ] UI-12 — Live readout panel for the selected body while simulating (position, velocity, speed, acceleration, forces, contacts, energy) with units, copy, pin

## Outliner
- [ ] UI-20 — Outliner: tree with groups/folders (from ED-20), drag to reorder/reparent with drop indicators, multi-select ranges (Shift/Ctrl), inline rename, eye/lock/solo toggles, colour tags and tag chips, per-row thumbnails (offscreen renders cached), search with filters (type, material, tag, locked/hidden, has-component), sort modes, context menu, virtualised for thousands of rows
- [ ] UI-21 — Selection sets: named selection groups (save/recall), quick-select by tag from the outliner

## Telemetry
- [ ] UI-30 — Telemetry charts as draggable/resizable widgets in the bottom dock: add any number of charts, each with multiple traces, dual y-axes, legends, colours, units; zoom/pan (wheel/drag), cursor with value readout at time, markers/annotations, pause/follow, clear/record length, per-chart export (PNG/CSV)
- [ ] UI-31 — More signals: position/velocity/acceleration components, angular velocity, momentum, angular momentum, kinetic/potential/total energy per body, power, joint angle/speed/torque/force, spring length/force, contact count/force, temperature, sensor values, custom expression traces (e.g. `speed(a) - speed(b)`), XY (phase) plots, histogram
- [ ] UI-32 — FFT/spectrum view for any signal with window selection and peak labelling (verified: a sampled 2 Hz oscillator peaks at 2 Hz), and a derived-signal panel (derivative/integral/RMS/min/max/mean)

## Onboarding and presentation
- [ ] UI-40 — Interactive spotlight tour engine (shared with GM-12) plus a first-run onboarding flow that teaches the basics; tips-of-the-day; context hints that appear when the user does something new (e.g. first selection)
- [ ] UI-41 — Presentation / photo mode: hide all UI (key), hi-res capture with camera presets, depth-of-field presets, lighting presets, optional turntable, on-screen caption/title overlay; 
- [ ] UI-42 — Quality-of-life: recent scenes list, favourites (templates/prefabs/maps/shapes), scene thumbnails everywhere, drag-and-drop files anywhere on the window (scene JSON, meshes, images, replays, prefab packs) with a clear drop overlay, "open recent" in File menu, paste scene JSON from the clipboard
- [ ] UI-43 — Friendlier errors & diagnostics: error boundary with explanation + "copy diagnostics" + recover options, WebGL/WASM/worker capability checks with plain-language guidance, Diagnostics panel (device, browser, GPU, limits, worker status, timings), Profiler panel (frame time breakdown: physics, readback, scene update, render, UI) with a rolling graph
- [ ] UI-44 — Shortcut cheat-sheet overlay (searchable, built from the command registry) and contextual tooltips with shortcut hints everywhere; status bar tips; empty-state illustrations for every list (no scenes, no selection, no joints…)
