# 12 · Editing tools and level-building helpers (package ED)

Depends on: foundation (commands/tools registries, group/path entity kinds), shapes (compound). All are undoable single commands, work in edit mode, and respect locked/hidden. Every tool has a toolbox/command entry, shortcut, hint bar text and an e2e or unit test.

## Implementation notes (package ED-A)

Built by seven parallel workers; all new code lives in `src/model/edit/` (pure), `src/app/edit/` (orchestration) and `src/ui/extensions/ed-*.ts` (registrations). `tests/edShortcuts.test.ts` loads every extension together so a shortcut clash (the loader skips a whole file on one) fails a unit test.

* **Shortcuts:** `O` lasso, `S` paint select, `Mod+I` invert, `D` path tool, `Shift+C` close/open path, `Y` symmetry, `Shift+Y` Array panel, `End` / `Shift+End` drop to ground / onto surface, `Shift+P` cycle pivot mode, `Shift+O` 3D-cursor tool, `Shift+G` Snap popover, `Mod+Shift+V` paste in place. Everything else is in the palette and the Edit menu.
* **Document fields added:** `GroupEntity.array` (linked arrays, sanitised; a missing source turns the group into a plain one on load). No migrations.
* **Open:** ED-20 "merge group into compound" waits for the shapes package's command (adapter in `src/app/edit/compoundAdapter.ts`). User prefabs use their own storage adapter (`src/app/edit/prefabStorage.ts`); it can be pointed at `src/app/storage/` later.
* **Known approximations:** drop-onto-surface uses bounding boxes; symmetry pairs are not saved; linked-array instances are regenerated from the source (direct edits to an instance are lost on rebuild); non-uniform group scale is approximate for members turned against the group axes (the UI says so).
