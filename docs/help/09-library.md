# Library

Scenes, prefabs and maps: start from something ready-made and keep your own work.

## Tabs of the left panel

| Tab | What is in it |
| --- | --- |
| Add | Shapes, soft bodies, lights, paths and joints, plus quick tips. |
| Prefabs | Ready-made assemblies: car, wheeled cart, motor wheel, piston, pendulum, hanging chain, seesaw, hinged door, spring and mass, brick wall, domino row and block tower. Click one to insert it at the centre of the view. |
| Maps | Environments to build on, searchable by name, category, tag or difficulty. |
| Scenes | *My scenes* (saved in this browser) and the built-in examples. |

## Examples

**File → Examples** and the *Scenes* tab list the built-in scenes: Jelly playground, Cloth drape and hammock, Tearing banner, Drivable car, Wrecking ball, Lever launcher, Piston press, Double pendulum, Springs and dampers, Friction lab, Billiards (zero-g), Domino run, Jenga tower, Rope bridge and Ball pit. Opening an example replaces the current scene; use **Ctrl+Z** if you did not mean to.

## Saving your work

- Your current scene is **autosaved** in this browser all the time.
- **File → Save to library** (**Ctrl+S**) keeps a named copy that appears under *My scenes*.
- **File → Export scene file** downloads the scene as a JSON file; **File → Import** (or dropping a `.json` file on the window) opens one.
- **File → Copy share link** packs the scene into a link you can send to someone.

Everything lives in your browser's local storage: clearing site data removes your saved scenes, so export the ones you care about.

## Empty lists

A search that finds nothing, or a library with nothing saved yet, shows a short hint instead of a blank panel.
