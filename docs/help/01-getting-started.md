# Getting started

PhysicsLab is a physics sandbox: build something, press **Simulate**, and watch (and poke) it move.

## The screen

- **Top bar** – the menus (File, Edit, View, Help), the scene name, the transport buttons (Simulate / Step / Stop), the speed buttons and the simulated clock.
- **Left panel** – your library: **Add** (shapes, soft bodies, lights, paths, joints), **Prefabs**, **Maps** and **Scenes**.
- **Viewport** – the 3D scene in the middle. The tool buttons float on its left edge, the view options on its right.
- **Right panel** – **Inspector** (properties of the selection), **Outliner** (every object as a tree), **World** (gravity, ground, solver settings) and **Help** (this panel).
- **Bottom dock** – live charts while the simulation runs, see [Telemetry and charts](telemetry).
- **Status bar** – object counts, physics step time, speed and frame rate, plus a tip.

## Your first five minutes

1. Open **File → Examples** and pick *Drivable car*, or press **Space** on the scene that is already loaded.
2. Press **Space** (or the *Simulate* button) to start the physics. Press **Space** again to pause.
3. While it runs, **drag a body** to throw it around. Keys bound to motors (for the car: W A S D) drive them.
4. Press **Shift+Space** to stop: the scene returns to the layout you built.
5. To build your own, choose *File → New scene*, then press **1** to add a box, **2** a sphere and so on. Move things with the gizmo (**W**), then press **Space**.

> Everything you do is undoable with **Ctrl+Z**, and your scene is autosaved in this browser.

## Finding things

- **Ctrl+K** opens the command palette: type any command, setting, scene, prefab or map.
- **?** opens the shortcut cheat-sheet, **F1** opens this help.
- Hover any button for a tooltip; it shows the shortcut when there is one.
