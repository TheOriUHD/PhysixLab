# Keyboard shortcuts

Every shortcut in one place, and how to find the rest. On a Mac, read **Ctrl** as **Cmd**.

## The cheat-sheet

Press **?** (or choose **Help → Keyboard shortcuts**) to open the cheat-sheet. It is generated from the commands the app really has, so it can never be out of date.

- Type to filter by name, category or key; **Up/Down** moves through the rows and **Enter** runs the command.
- Tick *Show commands without shortcuts* to search every command, not only the ones with keys.
- **Esc** closes it.

**Ctrl+K** opens the command palette, which finds commands, settings, scenes, prefabs and maps. **F1** opens this help.

## Simulation

| Key | Action |
| --- | --- |
| **Space** | Start / pause / resume |
| **Shift+Space** | Stop and return to the editable layout |
| **.** | Advance one physics step |

## Tools

| Key | Tool |
| --- | --- |
| **Q W E R** | Select, Move, Rotate, Scale |
| **J** | Joint tool |
| **M** | Measure distance |
| **B** | Blast |
| **T** | Fire projectiles |

## Editing

| Key | Action |
| --- | --- |
| **Ctrl+Z**, **Ctrl+Shift+Z** / **Ctrl+Y** | Undo, redo |
| **Ctrl+C**, **Ctrl+V**, **Ctrl+D** | Copy, paste, duplicate |
| **Delete** / **Backspace** | Delete the selection |
| **Ctrl+A** | Select all |
| **Ctrl+G**, **Ctrl+Shift+G** | Group, ungroup |
| **H** / **L** | Hide / show, lock / unlock the selection |
| **Arrow keys** | Nudge the selection (1 m with **Shift**) |
| **Esc** | Cancel the tool, then deselect |
| **1** – **8** | Add the numbered shape at the view |

## View and camera

| Key | Action |
| --- | --- |
| **F** | Frame the selection |
| **Home** | Frame everything |
| **C** | Camera follows the selection |
| **G** | Grid snapping on / off |
| **X** | Gizmo world / local space |
| **Right drag** or **Alt drag** | Orbit |
| **Middle drag** | Pan |
| **Scroll** | Zoom |

## Files and help

| Key | Action |
| --- | --- |
| **Ctrl+S** | Save to library |
| **Ctrl+K** | Command palette |
| **?** | Shortcut cheat-sheet |
| **F1** | Help |
| **Shift+M** | Mute sound |

Typing in a text field never triggers a shortcut (except **Ctrl+K** and **F1**).
